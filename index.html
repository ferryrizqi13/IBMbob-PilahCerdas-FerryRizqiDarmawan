📖 Panduan Pemilahan Sampah

Cari nama barang untuk menemukan panduan penanganan yang tepat. Penerimaan dan metode pengolahan dapat berbeda tergantung fasilitas di daerah Anda.

🌿

Organik

Sampah dari bahan alami yang dapat terurai secara biologis menjadi kompos.

Contoh: Sisa sayuran, kulit buah, daun kering, ampas kopi, sisa nasi.

Anorganik (Daur Ulang)

Sampah yang berpotensi didaur ulang jika bersih dan diterima oleh fasilitas setempat.

Contoh: Botol plastik bersih, kertas bersih, kardus, kaleng.

Penanganan Khusus

Sampah berbahaya dan beracun (B3). Jangan dibuang sembarangan atau dibakar.

Contoh: Baterai bekas, elektronik rusak, lampu TL/LED bekas.

ℹ️ Tentang PilahCerdas

PilahCerdas adalah platform edukasi pemilahan sampah yang ditujukan untuk pelajar, mahasiswa, keluarga, dan masyarakat umum. Kami hadir untuk mempermudah akses informasi pengelolaan sampah yang benar dan bertanggung jawab.

Website ini bersifat statis, berjalan sepenuhnya di browser, dan tidak terhubung ke server manapun. Seluruh data aktivitas Anda disimpan secara lokal di browser dan tidak dikirimkan ke pihak mana pun.

🔒 Data Anda tersimpan lokal. Tidak ada server, tidak ada pelacakan.
🎯

Target Pengguna

Pelajar, mahasiswa, keluarga, dan masyarakat umum yang ingin belajar memilah sampah dengan benar.

⚙️

Teknologi

HTML5, Tailwind CSS, Vanilla JavaScript, localStorage. Kompatibel dengan GitHub Pages.

🧪

Status AI

Fitur AI berjalan dalam Mode Demo menggunakan aturan lokal. Belum terhubung ke model AI eksternal — tidak ada API key di frontend.

📋

Data Panduan
